# 🎮 DevBreak Games - Fun Games for Software Employees

A collection of coding-themed games designed specifically for software developers to take fun mental breaks during work hours!

## 🚀 Live Demo

Simply open `index.html` in your web browser to start playing!

## 🎯 Features

### 6 Engaging Games for Developers

1. **🧠 Code Memory Challenge**
   - Test your memory with programming language sequences
   - Remember and repeat patterns of popular languages
   - Increasing difficulty levels

2. **🐛 Bug Hunt**
   - Find and fix syntax errors in code snippets
   - Timed challenges to improve debugging skills
   - Real JavaScript code examples

3. **⌨️ Code Typing Speed**
   - Type real code snippets as fast as possible
   - Measures WPM (Words Per Minute) and accuracy
   - Algorithm and function examples

4. **🤔 Algorithm Quiz**
   - Quick-fire questions about programming concepts
   - Data structures, algorithms, and complexity
   - Educational explanations for each answer

5. **📚 Stack Overflow Simulator**
   - Answer programming questions like on Stack Overflow
   - Earn reputation points for correct answers
   - Real-world JavaScript problems

6. **⛳ Code Golf**
   - Write the shortest code possible to solve challenges
   - Test your solutions against multiple test cases
   - Compete for the best (shortest) score

## 🎨 Design Features

- **Developer-Friendly Dark Theme**: Easy on the eyes during long coding sessions
- **Modern UI**: Clean, responsive design that works on all devices
- **Syntax Highlighting**: Code displays with proper color coding
- **Animations**: Smooth transitions and hover effects
- **Score Tracking**: Local storage keeps track of your best scores
- **Mobile Responsive**: Play on any device

## 🏆 Scoring System

- **Memory Game**: Points based on level reached
- **Bug Hunt**: Number of bugs fixed within time limit
- **Typing Speed**: Words per minute (WPM)
- **Quiz**: Number of correct answers
- **Stack Overflow**: Reputation points earned
- **Code Golf**: Fewest characters used to solve challenges

## 🎮 How to Play

1. **Open the Website**: Load `index.html` in your browser
2. **Choose a Game**: Click on any game card to start
3. **Follow Instructions**: Each game has clear instructions
4. **Beat Your Score**: Try to improve your high scores
5. **Take Breaks**: Perfect for 5-10 minute coding breaks!

## 🔧 Customization

### Adding New Games
1. Add a new game card in `index.html`
2. Create the game logic in `games.js`
3. Add any specific styling in `styles.css`

### Modifying Existing Games
- **Questions/Challenges**: Edit the arrays in `games.js`
- **Styling**: Modify CSS variables in `:root` for theme changes
- **Difficulty**: Adjust timing, scoring, or complexity parameters
